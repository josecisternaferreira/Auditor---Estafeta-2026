# 📊 Auditor Estafeta 2026

Aplicación web para auditar Estados de Pago de Estafeta Chile.

## Características

- ✅ Verifica tarifas automáticamente contra tarifa oficial 2026
- ✅ Aplica 20% descuento corporativo SERVI-ALL
- ✅ Detecta ramales (Mejillones, etc.) y aplica cargos adicionales
- ✅ Identifica sobrecobros y subcobros
- ✅ Genera reporte descargable en Excel
- ✅ Interfaz web simple y fácil de usar

## Uso

1. Sube tu Estado de Pago (Excel)
2. Haz clic en "AUDITAR"
3. Descarga los resultados

## Tecnología

- Python 3.11
- Streamlit
- Pandas
- OpenPyXL
